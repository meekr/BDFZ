# P7 记录：交付（标准渲染、Web 浏览项目）

日期：2026-11-17　状态：**完成，门槛通过**

## 1. 标准渲染（Cycles）

- 视点统一定义在 `data/views.json`（Blender 世界坐标 eye/target/焦距，16:9），Blender 与网页共用同一份数据，保证机位一致。
- `blender/build/views.py` 建 `VIEW_Cameras` 集合；`blender/build/render_cli.py` 命令行渲染（后台 Blender + Metal GPU，避免阻塞 MCP 连接）：
  `Blender -b blender/bdfz.blend --python blender/build/render_cli.py -- <id|all> [samples] [pct] [out_dir]`
- 出图 `renders/`：鸟瞰、星形庭院、北侧主入口、宿舍庭院、体育及艺术中心（1920×1080，Cycles 128 采样 + 降噪，5 张共约 1 分钟）。
- 色彩与光照修正（P7 中发现）：Nishita 天空会自带日盘，与日光灯重复计光导致整体过曝（原设置靠 AgX + 曝光 −0.8 掩盖）；改为关日盘、天空强度 0.25、日光 3.5、曝光 0，AgX + Medium High Contrast。加 `Landscape_FarGround` 大地面，避免俯视时露出地平线以下的深色天空。学术中心屋面材质调深（0.13/0.15/0.19、粗糙度 0.55）。

## 2. glb 导出

- `blender/build/export_glb.py` → `web/public/bdfz.glb`：**0.47 MB**（预算 ≤ 25 MB），Draco 压缩（位置量化 14 bit），贴图 WebP。
- 柱子（184）与树（565）按"同网格物体挂到同一空物体下"导出为 `EXT_mesh_gpu_instancing`（Blender 导出器只对空物体子级做实例化，需先分组，只在导出进程内改、不保存）。
- 每个节点写 `extras`：`layer`（building / landscape / site）与 `bldg`（建筑编号），供网页图层开关、标注与信息卡。

## 3. Web 浏览项目（`web/`，Vite + Three.js）

- 单页：轨道浏览（OrbitControls，阻尼）；5 个预设视点（与标准渲染同机位，横向视场按 36 mm 画幅换算）；三栋建筑的名称标注与信息卡（数据 `web/public/scene.json`，由 `tools/p7_web_assets.py` 从 `data/*.json` 生成）；图层开关（建筑 / 景观 / 场地）；2024 图纸叠图（01 彩色总平面、02 屋顶平面，按 `data/frames.json` 重采样到世界网格，Z 0.3 铺设，透明度可调）。
- 相机横向视场与 Blender 一致（竖屏时放宽到 aspect 0.8 下限，避免建筑过小）。
- URL 参数：`?view=<id>` 初始视点、`?clean` 隐藏 UI（截图对比用）、`?stats` 右下角性能、`?capture` 保帧缓冲。
- 移动端：面板可折叠、像素比限 1.5、阴影贴图 2048。
- `npm run build` → `dist/`（约 3 MB，含 Draco 解码器，Vite 从 three 打包），`base: './'` 相对路径，可直接部署为静态站点。预览 `npx vite preview`。
