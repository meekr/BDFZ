## 二、做法与依据

- **地表**：卫星 ExG 植被指数 + 纹理方差分草地/铺装/土色，作为平面 UV 贴在校园地坪、操场平台、北广场、学术中心平台、宿舍基座的顶面。学术中心庭院的斜向铺装（04 的浅蓝 X 形带）由分类图自然带出。
- **树**：树冠掩膜（植被 + 高纹理）距离变换取极大值 → 位置与冠幅；简化树 = 圆锥干 + 二十面体冠，全部实例共用一份网格。按射线落到地表/平台上；落在建筑与跑道上的剔除。
- **北入口**：大台阶 12 级，y 117（顶，Z 0）到 y 80（底，Z −6），宽 x −80…10；门房两座（x −90…−55、0…32，y 66…79，高 4.5 m，推定）。
- **下沉庭院**：02 上东北 (58,−4) 与西南 (−75,−102) 两块在卫星上为深阴影区，判定为平台内的下沉庭院，平台开洞通至 Z −6。
- **天空**：Nishita，太阳高度 40°、方位西南（海口 20°N 冬季午后），Filmic，曝光 −0.8。
