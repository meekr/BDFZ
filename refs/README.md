## 可信度分级

| 级别 | 含义 | 用法 |
|---|---|---|
| **A** | 设计方公开发布的 2024 建成版图纸 | 平面几何、标高、层数的建模依据 |
| **A** | 2024 建成后实景照片（白羽摄） | 立面、材质、体量关系的校正依据；与图纸冲突时以照片反映的建成状态为准，并记入差异表 |
| **B** | 2020 方案图纸、2020 施工期照片 | 结构形式、构件位置的辅助参考；方案后有改动，不直接用于定形 |
| **C** | 学校官网活动照片 | 只看局部材质、室内（泳池、报告厅、校门石） |
| **D** | `../legacy_unverified/` 里的数据与渲染截图 | **可能有错**。只能作为"待核对的线索"，任何数值进入新模型前必须在 A 级资料上重新量取或复核 |
