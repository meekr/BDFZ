结论先说
① 设计平面图找到了，而且是设计方授权的官方图纸：总平面、屋顶平面、三层平面、长/短轴剖面、宿舍各类型单元平面与轴测示意图，均带功能图例、层数、标高和 50m 比例尺，可量测。
② 没有找到单独的「场馆详图」——游泳馆、篮球馆、1000 人剧场、图书馆的单体平面/施工图未公开；它们在总平面与剖面里只以体量出现。但设计方 2020 年发布的方案说明对各场馆的功能分区、标高、结构形式有非常详细的文字描述（见下文），可作为建模依据。
③ CAD / DWG 施工图未公开。施工图属于设计方与业主的受控技术文件，公开渠道只有建筑媒体发布的 JPG 图纸。下文给出合法获取途径。

三、场馆：图纸里有什么，缺什么

场馆官方图纸中的呈现设计方文字说明（有方 2020 方案 / 2024 新作）
体育及艺术中心彩色总平面标注「体育及艺术中心 SPORTS / 2F」；长轴剖透视显示西侧扁平两层体量；无单体平面依附地势形成 L 形体量，分东西两区：西侧体育中心、东侧艺术中心观演区；主入口在转角处的室外架空空间；整栋 24m 高，分 0m 与 12m 两层
游泳馆 / 篮球馆总平面与剖面中可见大跨体量，无独立平面50m 标准泳池、篮球、羽毛球、乒乓球、跆拳道、空手道、体操、瑜伽等标准场馆合理布置在两层内；更衣淋浴与辅助空间置于夹层；篮球场与游泳馆均采用网架结构实现大跨度无柱空间；两侧玻璃幕墙双向自然采光
剧场（成就中心）无线条平面艺术中心观演区一层通高，由西向东为黑匣子（暗室）、1000 人标准剧场、舞蹈排练室；剧场含观众厅、舞台、后台辅助用房，后台设装卸平台供大型道具升降
图书馆 / 创客短轴剖面图例中标出「图书馆 LIBRARY」；公共服务功能分区图位于「云」下方底层，与创意工坊、演艺广场、实验室、多媒体教室一起构成底部公共层
学术中心（翔云）三层平面图完整（8 类功能图例 + 50m 比例尺）、等轴示意图、短轴剖面45 组钢柱支撑；3–4 层东西北三翼为初中书院，3–5 层南侧为高中教室；底层四栋单体对角斜坡围合中央广场
宿舍综合楼单元平面、高中/初中/职工宿舍轴测、局部等轴示意图（最详细的一组）4 个相连单元，高度由北向南递减；4 大庭院 + 16 个 10m 净宽小庭院；套间户型 = 4 间卧室 + 公共客厅 + 独立卫浴
400m 田径场彩色总平面、屋顶平面、线稿总平面均完整；带入口与标高跑道环绕体育中心体量，室外运动场抬高，下方为地下车库，两侧以阶梯式看台与两层场馆相连
CAD / DWG 核查结论
检索了以下渠道，均未发现可公开下载的 AutoCAD 施工图源文件：设计方 Crossboundaries 官网项目页、ArchDaily / 有方 / 建筑学院 / World-Architects / 知末 / 新浪的项目发布页（仅发布 JPG 图纸）、海口市政府与秀英区政府规划批前公示（仅检索到 2021 年接待室/保安室临时建筑的许可公示，无主体施工图附件）、环评与招采公告、筑龙等资料站（有该项目的资料打包页，但需登录/积分，且为方案文本转载，不是官方 CAD）。

为什么没有：建筑施工图（含各层平面、节点、结构、机电）由业主、设计方与施工图审查机构保管，属受控技术文件，通常不对外发布；媒体发布的是经过排版的方案/扩初图纸。

合法获取途径（按可行性排序）：
1. 联系学校基建/后勤部门或举办方（恩祥集团）申请查阅竣工图档案；
2. 向设计方 Crossboundaries 或合作单位「海南华磊建筑设计咨询有限公司 / DGN Design Studio」申请图纸授权（页面版权归设计方，需书面许可）；
3. 向海口市自然资源和规划局 / 秀英区行政审批服务局申请政府信息公开，索取建设工程规划许可附图（一般为 PDF 总平面与立面，非 CAD）；
4. 若用于教学研究，可基于本图纸集的高清 JPG + 50m 比例尺自行矢量描图（总平面与三层平面精度足够，误差约 0.5–1m）。

四、用途与精度提示

  • 本图纸集可直接用于核对上一版 3D 模型的形态与尺寸：彩色总平面给出三大功能体块、层数与出入口；三层平面图的 0–5–10–20–50m 比例尺可换算学术中心真实进深；线稿总平面带尺寸链，可复核 400m 跑道与建筑间距。
  • 2020 方案与 2024 建成版存在差异（例如建筑带的屋面处理、宿舍单元划分），以 2024 建成版为准。
  • 图纸均带 © Crossboundaries 版权，仅供个人学习与研究使用，请勿转载或商用；引用请注明设计方与来源媒体。
  • 本图纸集是「方案 / 扩初深度」，不含轴网坐标、构造节点、门窗表与设备管线，不能替代施工图或竣工 BIM。
